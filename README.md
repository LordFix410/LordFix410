## Lo que más me ha costado y más he disfrutado

### Control Personal

App de productividad que hice para mí mismo. Planifica actividades, lleva temporizadores, hábitos y metas, y detecta qué estoy haciendo en la PC para avisarme cuando me distraigo. Con visión por computadora mide mi concentración y hasta cuenta mis flexiones. También se conecta con una app Android por una API HTTP local y tiene instalador para Windows.

`Python` `Flask` `SQLite` `OpenCV` `MediaPipe` `Kotlin`

[Código](https://github.com/LordFix410/Control-Personal) · [Descargar](https://github.com/LordFix410/Control-Personal/releases/latest)

### Sistema de Ventas

Aplicación de escritorio para manejar clientes, productos, inventario y ventas sobre una base de datos relacional.

`C#` `.NET` `SQL Server`

[Código](https://github.com/LordFix410/Sistema_de_Ventas) · [Instalador](https://github.com/LordFix410/Sistema_de_Ventas/releases/download/v1.0.0/InstaladorSistemaVentas.exe)

### Plataforma Multimedia

Servidor web propio para guardar, organizar y compartir videos y presentaciones, tanto en red local como con acceso remoto a través de Cloudflare.

`C#` `ASP.NET Core` `Kestrel` `Cloudflare`

[Ver demo](https://servidor-videos.abdielcarcuz.workers.dev/HTML/index.html)

### Plataforma de Música

Biblioteca musical en la web: administrar canciones, armar playlists y controlar la reproducción desde distintos dispositivos.

`JavaScript` `HTML` `CSS`

[Ver demo](https://servidor-videos.abdielcarcuz.workers.dev/HTML/Musica.html)

### Reconocimiento de voz offline

Sistema local que entiende comandos por voz, los interpreta con un lexer/parser propio y automatiza búsquedas en aplicaciones de escritorio, sin depender de internet.

`Python` `Vosk`

### Producción multimedia en vivo

Paneles web y automatizaciones para manejar cámaras, escenas, overlays y todo lo audiovisual durante una transmisión.

`OBS Studio` `Streamer.bot` `WebSocket` `JavaScript`
